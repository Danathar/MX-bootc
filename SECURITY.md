# Security policy

This is an experimental image and should not be used for sensitive workloads. It currently does not claim an enforcing SELinux policy, and its installer examples intentionally use the placeholder password `changeme`.

Do not report security-sensitive details in a public issue. Use the repository's private security reporting mechanism when available, or contact the maintainers directly. Include the affected commit/image digest, `bootc status`, and a minimal reproduction without credentials or private data.

Installer users must replace the example password immediately after first login. Never publish an image or installer configuration with a real password, signing key, or SSH private key embedded in it.
